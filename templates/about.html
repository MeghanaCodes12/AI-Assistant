🤖 About AI Assistant

An AI-powered web application built using Flask and Google's Gemini AI to assist users with intelligent responses, text summarization, and creative content generation.

🎯

Project Objective

To develop an intelligent AI assistant capable of answering questions, summarizing text, generating creative content, and collecting user feedback.

✨

Main Features

  • Answer Questions
  • Summarize Text
  • Creative Content Generation
  • Feedback Collection
  • History Management
  • Analytics Dashboard
  • Dark Mode
🛠

Technologies Used

  • Python
  • Flask
  • Google Gemini API
  • HTML5
  • CSS3
  • JavaScript
  • Chart.js
